## 🌱 About the Project

Farmers visiting government Minimum Support Price (MSP) procurement centres often face long waiting hours, overcrowding, and uncertainty about procurement schedules and payment updates.

**Smart Farmer Procurement Queue Manager** aims to make this process more organised, transparent, and convenient through a simple, user-friendly web application.

The platform helps organise farmer registrations, generate tokens, manage procurement queues, and track crop procurement and payment statuses. It focuses on improving coordination at government procurement centres and reducing unnecessary waiting for farmers.

## 🎯 Objectives

- Reduce long waiting times and overcrowding at procurement centres.
- Simplify farmer registration and slot booking.
- Organise queues through unique token generation.
- Provide clear procurement status updates.
- Improve transparency in procurement and payment tracking.
- Create a foundation for future integration with authorised government systems.

## ✨ Key Features

### 👨‍🌾 Farmer Registration
Register farmers and maintain their basic details for procurement activities.

### 🗓️ Slot Booking
Organise farmer visits into designated procurement time slots.

### 🎫 Token Generation
Generate unique tokens to help maintain an orderly queue.

### 📋 Queue Management
View registered farmers, search records, and manage queue statuses.

### 🚜 Procurement Tracking
Track different stages of procurement, including waiting, weighing, acceptance, rejection, and payment processing.

### 💰 Payment Status Tracking
Display payment-related statuses to help users understand the progress of procurement payments.

### 📊 Interactive Dashboard
View a summary of registered farmers and ongoing procurement activities.

## 🚀 Getting Started

You can run the project locally in a few simple steps.

**1. Clone the repository**

```bash
git clone https://github.com/jass096/smart-farmer-procurement.git
```

**2. Open the project folder**

```bash
cd smart-farmer-procurement
```

**3. Launch the website**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code for a convenient local development experience.

## ⚠️ Current Limitations

This project is a prototype created for educational and demonstration purposes. It currently uses browser Local Storage, so data is saved only in the browser where it was entered. It is not connected to live government procurement systems or actual payment services.
